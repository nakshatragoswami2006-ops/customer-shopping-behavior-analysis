# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes 3,900 customer purchase records to understand shopping behavior, spending patterns, product preferences, and customer loyalty. The goal is to identify useful business insights and suggest strategies to improve sales and customer retention.

## Tools and Technologies

- Python
- Pandas
- NumPy
- SQL
- PostgreSQL
- Jupyter Notebook

## Dataset

- Total records: 3,900
- Total columns: 18
- Missing values: 37 in the Review Rating column
- Missing values were handled using median imputation.

## Project Workflow

1. Loaded the dataset using Pandas.
2. Explored the data and calculated summary statistics.
3. Cleaned missing values.
4. Created age groups and purchase-frequency features.
5. Integrated the data with PostgreSQL.
6. Analyzed customer behavior and purchasing patterns.
7. Identified business insights and recommendations.

## Key Findings

- Female customers generated slightly higher total revenue than male customers.
- Some customers using discounts spent above average.
- Blouses received the highest customer ratings, followed by dresses and shirts.
- Express shipping customers spent an average of $65 per purchase, compared with $58 for standard shipping.
- Subscribers showed 68% higher spending than non-subscribers.
- Customers were segmented into Loyal (15%), Returning (35%), and New (50%).

## Business Recommendations

- Promote subscriptions with exclusive benefits.
- Introduce loyalty programs to encourage repeat purchases.
- Use targeted marketing for high-value customer segments.
- Promote highly rated products.
- Convert new customers into returning and loyal customers.
- Optimize discount strategies to improve revenue.
